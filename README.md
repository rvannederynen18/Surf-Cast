# SurfCast

Surf fishing forecast for the Florida east coast, Fernandina to Melbourne: best hours, best beaches, target species and migration map.

**Open it here:** https://rvannederynen18.github.io/surfcast/

- `index.html` is the whole app (it's the SurfCast file, renamed so the link opens it directly).
- Uses free live data from NOAA, the National Weather Service and Open-Meteo, so it needs internet.
- Settings are saved in the browser on each device.
- For the TV: open the link on the PC and press **Full screen** in the top bar. Esc returns to normal view.

To update: upload a new `index.html` (rename the new SurfCast file to `index.html` first).
